What's new in 0.2.0
-------------------

* Language servers: when one is installed (pyright, gopls, clangd,
  rust-analyzer, ruby-lsp, TypeScript 7 and more), Intellekt uses it for
  smarter suggestions, error underlines, parameter help, auto-import, go
  to definition, references, rename, formatting, inlay hints and code
  lens. Without one, the offline index works as before.
* Python: finds your virtual environment, suggests modules you have not
  imported yet, and organizes imports or formats with ruff, isort or
  black.
* Suggestions continue after calls and literals, such as
  datetime.now(). or "text".strip().
* Finds tools installed with Homebrew, nvm, Go, Cargo, gem and pip, with
  fixes for Windows and Linux.
* No key bindings are added by default. F12 and Shift+F12 use the
  language server. VS Code-style shortcuts you can copy are in
  Preferences > Package Settings > Intellekt > Key Bindings.

Settings have moved into one block per language. If you used the old
flat keys, move them, for example:

    "python_executable": "..."  ->  "python": {"executable": "..."}
    "lsp_servers": {"cpp": false}  ->  "cpp": {"server": false}
